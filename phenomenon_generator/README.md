# LOTO7｜局所現象を再現する配置生成機構 v0

観測された局所現象を、**実際に7点配置を作れる明示的な操作**へ落とす小さな生成機構です。

これは抽選原因の説明ではありません。  
また、次回にどの操作を選ぶべきかを決める予測器でもありません。

v0の問いは一つだけです。

> **何を残し、何を変えれば、その景色を再現できるか。**

## v0の基本姿勢

- 1回を1〜37上の重複しない7点として扱う
- 元配置を保持する
- 保存条件と操作は人が明示する
- 条件衝突は棄却する
- 黙って補正しない
- 「再現できる」と「次に起きる現象を選べる」を分離する

## 保存対象

保存条件として現在実装しているのは:

- `points` — 指定点が残る
- `region_count` — 指定領域内の点数
- `gaps` — 6個の隣接間隔
- `blank` — 指定区間が空白
- `width` — 最小点から最大点までの幅

毎回すべてを指定する必要はありません。保存条件なしも許します。

## 操作

### translate / 移動

選んだ点群へ同じ変位を加えます。点ごとの微小ずれは `offsets` で明示できます。

### deform / 変形

指定中心の周囲で選んだ点だけを倍率変形します。負倍率なら反転も作れます。

### reallocate / 再配置

指定点を外し、別の点を明示的に置きます。空白への流入や局所組み替えを作る最小操作です。

### rereference / 再参照

直前ではなく、初期配置や過去生成ステップの点を再び材料として使います。

## 実行

```bash
cd phenomenon_generator
python cli.py examples/324_326.json
python cli.py examples/287_289.json
python cli.py examples/309_310.json
```

結果には各操作の before / after と保存条件の判定が残ります。

## v0でやらないこと

- 次の操作の自動選択
- 自動分類
- 類似度ランキング
- Null比較
- 予測
- 因果説明
- 条件違反の自動修正
- 「下降したから反発する」のような規則

## 評価の分離

1. **再現面** — 明示した操作で観測された景色を作れるか
2. **選択面** — 未来を見ずに次の操作を選べるか

v0は1だけを扱います。2は別のProbeです。
