# Astra Model

Astraが独立に観測・構造化したLOTO7局所現象を保持する。

## Boundary

- Flow ModelとはObservation層で混ぜない
- 観測とStructureを分離する
- 同型に見えても共通原因を置かない
- Prediction / causal claim / Null superiority は含めない
- Observationは原形を残し、Structureは後段の機械表現として別保存する

## Layout

- observations/ : Astraが観測した原形
- structures/   : 機械比較のための最小構造表現
